# Sistema de Controle de Estoque

Um sistema simples em Node.js e JavaScript para gerenciamento e controle de estoque.

## 📌 Funcionalidades

- Cadastro, edição e remoção de produtos
- Controle de entrada e saída de estoque
- Alertas de itens com estoque baixo
- Histórico de movimentações

## 🛠️ Tecnologias

- **Node.js**
- **JavaScript**

## 🚀 Como Executar

1. **Clonar o repositório:**
   ```bash
   git clone https://github.com/seu-usuario/sistemaEstoque.git
   cd sistemaEstoque
   ```

2. **Instalar as dependências:**
   ```bash
   npm install
   ```

3. **Iniciar a aplicação:**
   ```bash
   npm start
   ```

Acesse a aplicação no seu navegador pelo endereço `http://localhost:3000` (ou porta configurada).
